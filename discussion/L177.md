# L177 ABDK zkSync v2 part 2 CVF-37 (Critical, 'Unclear behavior', fixed): _proof.commitments partly caller-supplied
Source: reports/linked/ABDK-ZKSync-Audit-v2-part2.pdf (ABDK, zkSync v1 phase 2 contracts).
Contract overwrites only the entries at commitmentIdxs with stored block commitments; other entries keep caller values and are passed to verifyAggregatedProof. ABDK asks 'Is this fine?': no attack is described. If those entries feed the aggregated proof's public input, the proof isn't fully bound to the stored commitments.
Proposal: Y P2 (public input not fully bound to stored commitments), PSS N, L. Alt N (no attack described).
