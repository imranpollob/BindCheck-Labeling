# L132 ABDK Tornado cryptographic review 5.2 (analysis, user mistakes): reused or stolen nullifier k blocks a coin
Source: reports/linked/Tornado_cryptographic_review.pdf. If k repeats (buggy software) or is low-entropy/stolen, only the first coin with that k can be withdrawn; an attacker can only interfere if they can guess or steal k. User-mistake analysis, no protocol flaw.
