# L148 · LIGHT · Linea contracts update (Diligence 2024-01) · 5.4 "Malicious Operator Might Finalize Data From a Forked Linea Chain" (Major, marked Fixed)
No chain ID in the finalization public input, so a forked chain's data+proof could be finalized. Resolution: Linea says chainId is a constant in the circuit, so the verifier key differs per chain ID; a fork's proof fails unless it uses the same chain ID.
- Chain ID is pinned via the VK the consumer uses (like L104/L152: config baked into the pinned program). A same-chain-ID "fork" is just a different history by the trusted operator.
