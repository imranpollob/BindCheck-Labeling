# L157 ABDK Nebra Spec Part I CVF-7 (Major): no range check on top byte of field-element byte decomposition
Source: reports/linked/ABDK_Nebra_SpecAudit_PartI_v_1_0.pdf. Circuit IDs and public inputs are decomposed into 32 bytes for Keccak; without bounding the top byte, field value x can be decomposed as x+p. The Keccak digest the contract checks (proof ID over circuit ID and public inputs) can then describe a different uint256 than the value the batch verifier actually verified. 'also found in the code'.
Proposal: Y P5 (encoding between verified field value and hashed bytes), PSS N, L. Alt N [circuit-soundness]. Similar to L062 (rater chose Y for unchecked field elements).
