# L021 · FULL · Nocturne (Zellic 2023-10, bfcbfcf) · 3.4 "Operation with zero joinsplits can be tampered with" (Low, fixed 50fe52a)
## Pass 1: report only
An operation's external calls are bound by its digest, which is a public input to each joinsplit proof. With zero joinsplits there is no proof, so the bundler can change the calls freely. Impact small: no assets are unwrapped, and no gas repayment so bundlers won't usually include it.
- C1: an operation is accepted with an empty proof set (verifier side accepts what it should reject). C2 met (external calls executed). C3 met (which calls run isn't fixed).
- Proposed: Y, P4 (batch verification vacuously passes with zero proofs; alt P1), PSS N, conf M. Severity Low; labeled by mechanism (§6).
