# L093 ToB Automata DCAP TOB-AUT-7 (High): RISC0/SP1 attestation may accept expired certificates
Source: reports/linked/2025-02-automata-dcap-attestation-onchain-pccs-securityreview.pdf. The zkVM output includes the verification timestamp, but verifyZkOutput never validates it; a prover uses an old timestamp so a long-expired (and dropped-from-CRL) compromised certificate verifies. The consumer ignores a context field the proof commits (cf. L195).
