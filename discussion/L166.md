# L166 · LIGHT · Blobstream X (Zellic 2024-03) · 3.5 "Tendermint X TendermintSkipCircuit skip function's return value need not be related to parameters" (Critical, fixed 1800e7c8)
CombinedSkipCircuit takes trusted_block / trusted_header_hash (the contract's latest trusted state) as public inputs, but skip() never constrains the hinted skip_variable to those inputs. An attacker verifies a chain from a fake trusted header with made-up validators and gets arbitrary data commitments.
- C1 met, C2 met (contract stores new header/data commitment), C3 met: the proof's starting point isn't bound to the trusted state the contract supplies. Same shape as L149 (Helios starting state not bound).
- Proposed: Y, P2 (state context not bound), PSS N, conf M.
