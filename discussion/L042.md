# L042 · FULL · Boundless marketplace (Veridise 2026, e2bc0cc) · V-BLMP-VUL-002 (sheet: V-BML-VUL-002) "Class-based request selectors can accept attacker-registered fake verifiers" (Medium, Fixed PR 2054)
## Pass 1: report only
A request can sign a verifier *class* instead of an exact verifier. Classes can allow permissionless instantiation, checked only by ERC-165. A prover registers a dummy verifier (or dummy assessor, if the verifier class needs a permissionless assessor class), selects it in the seal, and gets paid for a bogus proof.
- C1 met (the router accepts). C2 met: payment. C3 met: which verifier/assessor checks the proof is prover-chosen, not pinned by the request.
- Proposed: Y, P4 (verifier not pinned by the consumer), PSS N, conf M (needs an opt-in permissionless class or a governance config).
