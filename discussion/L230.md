# L230 · PSS · RISC Zero Boundless (Veridise 2025-04, 71de107) · V-RISC0-VUL-004 "The set verifier accepts non-leaf nodes" (Medium, Fixed)
RiscZeroSetVerifier computes a Merkle root from (claimDigest, path) with no leaf/node domain separation, so any intermediate node or the root itself verifies as a "claim".
- PSS Y: aggregation (set) verifier accepts what it should reject.
- Binding: C1 met. C3: the accepted "claim" is an internal hash; to make it a meaningful claim digest the attacker needs a SHA-256 collision between a node and a claim struct. Nothing a consumer acts on can be steered. The report's impact is generic ("verify invalid claimDigests").
