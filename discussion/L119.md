# L119 · LIGHT · RISC Zero Kailua (Veridise 2025-02, 6e2ce8f) · V-KLA-VUL-016 "Not all fields included in rollup hash" (Medium, Fixed bd76b76)
config_hash, committed in the journal and checked on-chain, omits eip1559 denominator/elasticity, genesis.l2_time, isthmus_time. The prover can vary those while keeping the hash, so a proof made under one rollup config passes for another.
- C1 met, C2 met (on-chain proposal/state resolution), C3 met (part of the rollup config the execution ran under isn't fixed).
- Proposed: Y, P2 (config context not bound), PSS N, conf M (report hedges "if these fields change behaviour"; they do affect base fee / fork activation).
