# L142 zk-bug-tracker #14: circomlib MiMC output assigned with = instead of <== (Tornado Cash)
Source: reports/linked/zk-bug-tracker-56a9966-README.md (entry 14, MiMC Hash: Assigned but not Constrained, found by Kobi Gurkan). circomlib MiMC used '=' instead of '<==' for the output, so the hash output is unconstrained; in Tornado this lets a prover fake the Merkle path to a known root and withdraw others' deposits. Broken hash gadget (computation), not an unauthenticated pass-through: the root the contract checks and the nullifier it records are proved public inputs.
Proposal: N, [circuit-soundness], H.
Duplicate of L087 (zkbugs config #32 is the same bug).
