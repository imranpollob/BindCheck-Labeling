# L028 · FULL · Symbiotic Relay (Sherlock contest 967, 2025-06, 57f80a9) · Z-1 "Malicious operator can alone, with any voting power smaller than quorum forge a proof" (High, fix 8d0d70b)
## Pass 1: report only
In the gnark circuit, a validator with key (0,0) placed last is skipped from the valset hash (so the hash still matches the real set the contract checks), but its voting power is still counted toward quorum, and adding (0,0) to the aggregate key needs no signature. One operator plus a fake (0,0) validator with huge voting power "proves" quorum and commits any next-epoch valSetHeader in Settlement.sol.
- C1 met, C2 met (commitValSetHeader stores the next header). C3: the valset hash, message and quorum the contract supplies are all bound; the attack uses an extra private witness entry whose voting power isn't constrained to zero. The circuit's "signers' power ≥ quorum" rule fails over private data.
- Same shape as L036 / L004 (in-circuit rule broken via private witness; consumer-read values locked). Proposed: N, NA, PSS N, conf M, [circuit-soundness]. Strongest counter: catastrophic effect.
