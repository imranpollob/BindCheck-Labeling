# L004 · FULL · Zkopru (Least Authority 2021-06, 4236fc8) · Issue E "Circuit Does Not Check the ERC-20 Sum Correctly" (Severe, Resolved; known issue found by team)
## Pass 1: report only
The tx circuit checks ERC-20 conservation only for token addresses that appear in input notes. An output note for a token that's not among the inputs (e.g. 1,000,000 USDC) passes, so the attacker mints notes and can withdraw rolled-up tokens.
- C1 met, C2 met (withdraw pays out). C3: the outputs the contract sees (note commitments / withdrawal hashes) are honestly computed from the proven values; what fails is the in-circuit conservation rule for unlisted tokens.
